# home

Landing page for UncleStev apps → https://unclestev.github.io/home/

- Edit the `APPS` list in `index.html` to set order, emoji, color.
- New repos show up automatically (with a NEW badge for 14 days).
- Tile images live in `img/<repo>.jpg` (800×500). Missing image → emoji tile.

Enable: Settings → Pages → Deploy from branch → `main` / root.
